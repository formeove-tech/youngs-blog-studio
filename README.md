# 영쓰의 블로그 작업실

사진, 네이버 플레이스 주소, 방문 메모를 모아 **방문기형 블로그 초안**을 만드는 웹앱입니다. 서버의 공용 API 키로 여러 사람이 사용하며, 이용자에게 키를 입력받거나 전달하지 않습니다. 최근 제주 글 2편은 문체 기준에서 제외했습니다.

## 실행하기

1. Node.js 24 LTS를 설치합니다: https://nodejs.org
2. 이 폴더에서 터미널을 열고 `npm start`를 실행합니다. 별도 `npm install`은 필요 없습니다.
3. 브라우저 주소창에 `http://127.0.0.1:3030`을 입력합니다.

Windows에서는 `start-windows.bat`, macOS/Linux에서는 터미널에서 `bash start.sh`로도 실행할 수 있습니다. 종료하려면 터미널에서 Ctrl+C를 누르세요. 서버는 해당 컴퓨터에서만 접속할 수 있도록 실행됩니다.

## 글 작성하기

1. 가게 이름을 직접 입력하거나 네이버 플레이스 주소로 불러옵니다. 불러오기는 공개 메타 정보의 가게 이름만 확인합니다. 네이버의 접근 제한이나 페이지 형식에 따라 실패할 수 있으므로, 주소·영업시간·주차·메뉴와 가격은 확인한 내용을 직접 입력합니다.
2. 사진을 최대 20장 추가합니다. 화살표로 순서를 바꾸고 사진별 설명을 적습니다. JPG, PNG, WEBP를 지원하며 업로드한 사진은 브라우저에서 긴 변 1,400px로 축소됩니다.
3. 방문 계기, 좋았던 점, 아쉬웠던 점 등을 메모합니다. 원하면 동행인·키워드·협찬 문구도 넣습니다.
4. **메모로 초안**은 API 키 없이 사용 가능합니다. 사용자가 입력한 메모를 제목·사진별 문단·정보·총평·해시태그로 구성합니다. 사진 내용 자동 인식과 AI 문장 생성은 하지 않습니다.
5. **AI로 방문기 작성**을 선택하면 사진과 메모를 OpenAI에 보내 문체를 반영한 글을 생성합니다. 이용자는 API 키를 입력하지 않습니다. 운영자가 서버에 키를 등록하면 AI 모드가 기본 선택됩니다. 이용료는 운영자의 OpenAI API 계정으로 청구됩니다.
6. 초안 제목을 선택하거나 본문을 클릭해 수정합니다. ‘글+사진 복사’는 이미지가 포함된 HTML과 일반 텍스트를 클립보드에 함께 넣습니다. 붙여넣는 편집기가 이미지 데이터를 제거하면 사진은 빠질 수 있습니다. 이때 각 사진 아래의 ‘이 사진 복사’로 한 장씩 붙여넣거나 ‘사진 ZIP’으로 내려받아 네이버 사진 업로드를 사용하세요. 사진 ZIP에는 순서대로 번호를 붙인 JPG와 사진 위치가 표시된 수정 본문이 들어 있습니다. 저장은 사진과 수정한 본문을 하나의 HTML 파일에 담습니다. 네이버 블로그에서 사진 배치·서식을 최종 확인해주세요. 자동 게시 기능은 없습니다.

사진·메모·초안은 새로고침하거나 앱을 닫으면 없어집니다. 작성한 글은 HTML로 저장해주세요. 원본 사진과 다르게 출력 사진은 웹용으로 축소됩니다.

## 운영자의 AI 연결

호스팅 서비스의 비밀 환경변수 `BLOG_WRITER_API_KEY`에 운영자의 실제 OpenAI API 키를 등록하고 서버를 재시작합니다. 로컬 개발에서는 `.env.example`을 `.env`로 복사해 설정해도 됩니다. 호환성을 위해 기존 `OPENAI_API_KEY`도 서버에서 읽습니다. 요청 본문으로 받은 사용자 키는 사용하지 않습니다. 키를 프런트엔드, Git, ZIP 파일에 포함하지 마세요.

서버는 키·사진·초안을 파일이나 로그에 기록하지 않습니다. AI 요청 시 입력한 사진·메모는 OpenAI로 전송됩니다. 실제 비밀키가 없는 배포 패키지이므로, 키를 등록하기 전에는 AI 연결 준비 중으로 표시합니다.

기본 모델은 `gpt-4.1-mini`이며 `.env`의 `OPENAI_MODEL`로 변경할 수 있습니다. 이미지와 JSON 출력을 지원하는 OpenAI Chat Completions 모델을 사용하세요.

## 웹주소로 공유하기 — Render 배포

1. 이 폴더의 배포 파일을 운영자 소유의 별도 GitHub 저장소에 올립니다. 기존 출퇴근 앱 저장소와 섞지 마세요. `.env`, `research`, API 키는 올리지 않습니다.
2. Render에서 **New → Blueprint**를 선택하고 해당 저장소를 연결합니다. 포함된 `render.yaml`이 Node.js 서비스와 실행 명령을 구성합니다. 요금제는 Render의 실제 조건을 확인하세요.
3. 배포 화면의 `BLOG_WRITER_API_KEY`에 실제 키를 비밀값으로 등록합니다. 환경 설정 초안에 등록한 값은 Render로 자동 이전되지 않으므로 배포 서버에도 별도로 설정합니다.
4. 배포가 끝나면 Render가 발급한 HTTPS 주소에서 사진 업로드와 AI 작성을 실제로 확인한 뒤 그 주소를 공유합니다. 이용자는 설치와 API 키 입력이 필요 없습니다. 필요하면 `PUBLIC_ORIGIN`에 실제 서비스의 HTTPS 원본 주소를 설정합니다.

다른 Node.js 호스팅에서는 `npm start`, `HOST=0.0.0.0`, 서비스가 지정한 `PORT`, `BLOG_WRITER_API_KEY`를 설정하면 됩니다. Docker 배포용 `Dockerfile`도 포함되어 있습니다. 호스팅 계정 연결, GitHub 업로드, 공개 배포는 아직 실행하지 않았습니다.

공용 AI는 프로세스당 동시 2건, 분당 10건, 하루 100건으로 제한합니다. `AI_DAILY_LIMIT`로 일일 횟수를 조절할 수 있습니다. 횟수는 메모리 기반이므로 재시작 시 초기화되고 여러 서버 간 공유되지 않습니다. 실패한 시도도 횟수에 포함되며, 금액 한도는 아닙니다. 비용 한도는 OpenAI 프로젝트 설정에서도 관리하세요. 이 버전에는 가입·로그인 기능이 없습니다.

## 검증

`npm test`로 입력 검증, 장소 주소 제한, 메모 초안의 사실 보존, AI 결과의 사진 연결 보정을 검사합니다.

실제 AI 호출은 API 키를 연결한 뒤 확인해야 합니다. 네이버 장소 불러오기에는 해당 네트워크 접근도 필요합니다. 메모 초안은 외부 서비스에 의존하지 않습니다.

문체 규칙은 `style-profile.md`에 있습니다. 문체 샘플의 원문과 조사 자료는 배포 패키지에 포함하지 않습니다.
