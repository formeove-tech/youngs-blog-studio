# 영쓰 네이버 작성 도우미 0.1.0 — 편집기 연결 시험판

이 버전은 실계정 네이버 편집기에서 검증 전입니다. 자동 발행 기능은 잠겨 있습니다. 사진 업로드나 소제목 설정을 확인하지 못하면 중지합니다. 네이버 인용구/구분선 전용 컴포넌트는 아직 지원하지 않으며 일반 텍스트로 입력합니다. 완전 자동 발행 완성본이 아닙니다.

## 설치
1. ZIP 압축을 풉니다.
2. 크롬 주소창에 chrome://extensions 를 입력합니다.
3. 오른쪽 위 개발자 모드를 켭니다.
4. '압축해제된 확장 프로그램을 로드합니다'를 누르고 manifest.json이 있는 extension 폴더를 선택합니다.
5. 크롬 퍼즐 아이콘에서 '영쓰 네이버 작성 도우미'를 고정합니다.

## 연결과 진단 — 먼저 이 순서로 확인
1. 영스에서 완성한 글을 열거나 저장한 HTML을 불러옵니다.
2. 확장 프로그램에서 '1. 현재 영스 글 가져오기'를 누릅니다.
3. 네이버 블로그에 본인이 로그인하고 새 빈 글쓰기 화면을 엽니다. 비밀번호를 프로그램에 입력할 필요가 없습니다.
4. 확장 프로그램에서 '편집기 진단 파일 저장'을 누릅니다.
5. 내려받은 youngs-editor-diagnostic.json을 이 채팅에 첨부합니다. 실제 편집기 구조에 맞춰 사진 업로드와 서식 조작을 검증할 때 사용합니다. 진단은 본문/사진 원본/쿠키/비밀번호를 포함하지 않습니다.

## 자동 입력 시험
검증용 빈 글에서 자동 발행 체크를 끈 채 '2. 현재 네이버 빈 글에 자동 작성'을 누릅니다. 편집기를 인식하지 못하거나 업로드/서식 확인이 실패하면 중지하며 작성된 내용은 지우지 않습니다. 실패한 글에 재실행하면 중복될 수 있어, 새 빈 글에서만 시작하도록 제한합니다. 네이버 화면 변경에 따라 보완이 필요합니다.

중지 버튼은 다음 작업을 막습니다. 이미 시작된 사진 업로드는 끝날 수 있으며 입력된 글/사진은 남습니다. 발행은 실행하지 않습니다.

## 보관
가져온 글/사진은 해당 크롬 확장 프로그램 로컬 저장소에 보관합니다. 외부 서버에 별도로 전송하지 않습니다. 사진을 네이버에 입력하는 시험을 실행하면 네이버에 업로드됩니다. '보관한 글·사진 지우기'로 로컬 데이터를 삭제할 수 있습니다.

## 검증 범위
JavaScript 구문과 패키지 구조를 검사했습니다. 실제 로그인한 네이버 계정에서 사진 17장 업로드·네이버 전용 소제목/인용구·저장·발행까지의 동작은 아직 검증하지 못했습니다. 전체 자동화는 위 진단 결과와 실기 검증 후 추가합니다.
