# 블로그 작업실 — 배포 준비 초안

## 확정한 제품 범위
- 이름: 블로그 작업실
- 대상: 직접 방문한 맛집 후기를 쓰는 사용자
- 첫 배포: 지인 사장님 5명 무료 베타
- 구성: 웹사이트에서 사진과 방문 메모로 초안 생성, 크롬 확장 프로그램으로 네이버 작성 보조
- 확장 프로그램 업데이트 목표: Chrome Web Store 배포 후 크롬의 기본 자동 업데이트 사용
- 현재 설치된 개발자 모드 확장 프로그램은 서버 배포만으로 자동 업데이트되지 않음

## 베타 시작 전 남은 검증
아래 검증 전에는 완전 자동 작성·자동 발행 기능으로 광고하거나 공개 배포하지 않는다.
- 사용자 크롬에서 글 가져오기 성공 및 사진 17장/순서 보존 확인
- 실제 네이버 편집기의 사진 업로드와 소제목/인용구/구분선 적용 확인
- 저장 후 다시 열어도 본문·사진·서식이 유지되는지 확인
- 선택한 블로그 계정과 대상 글 확인, 중복 발행 방지 및 실패 중지 검증
- 자동 발행은 위 검증 전 비활성 상태 유지
- 5명 베타는 모집 규모이며, 현재 가입 제한/5명 계정 제한이 구현됐다는 의미가 아님

## 웹스토어 등록 설명 초안
블로그 작업실은 직접 다녀온 맛집의 사진과 방문 메모를 후기 초안으로 정리하고, 네이버 블로그 작성 과정을 돕는 도구입니다.
실제 방문 경험과 본인이 촬영한 사진을 사용하며, 게시 전 사실과 사진 배치를 확인해주세요.
현재 연결 시험판은 글·사진 가져오기, 저장한 HTML 읽기, 편집기 진단, 제한적인 초안 입력을 제공합니다.
네이버 전용 서식과 자동 발행의 실계정 검증은 진행 전입니다.

## 권한 설명 초안
- activeTab: 사용자가 실행한 현재 탭을 확인하고 작성 도우미를 연결
- scripting: 허용된 영스 원본 도메인과 네이버 블로그 편집기에 로컬 패키지 코드 실행
- storage: 사용자가 가져온 글·사진과 작업 상태를 해당 크롬에 보관
- unlimitedStorage: 여러 장의 내장 사진이 기본 로컬 저장 용량을 넘을 수 있어 필요
- host_permissions: youngs-blog-studio.onrender.com 및 blog.naver.com으로 한정
- 원격 JavaScript 다운로드·실행 방식으로 업데이트를 우회하지 않음

## 데이터 처리 안내 초안 — 게시 전 운영자 연락처와 URL 확정 필요
확장 프로그램은 사용자가 선택한 후기의 제목·본문·사진을 크롬 로컬 저장소에 보관합니다.
네이버 작성 실행 시 사진과 본문이 사용자의 로그인된 네이버 편집기로 전달됩니다.
별도 운영자 서버로 확장 프로그램이 원문·사진·쿠키·비밀번호를 전송하지 않습니다.
편집기 진단 파일에는 페이지 경로와 편집기 구성요소의 태그·클래스·버튼 이름이 포함될 수 있습니다. 본문 원문·사진 원본·쿠키·비밀번호를 수집하도록 구현하지 않았습니다.
사용자는 확장 프로그램의 보관 데이터 삭제 기능으로 글·사진을 지울 수 있습니다.
웹사이트의 AI 작성 기능은 별도이며, 실행 시 사진과 메모를 웹사이트 서버 및 OpenAI로 전송합니다. 웹사이트에서 해당 안내를 표시해야 합니다.
이 안내는 현재 구현을 설명하는 초안입니다. 등록 운영자 연락처·최종 개인정보처리방침 URL·배포 기능 범위를 확정하기 전 웹스토어 제출용 최종본으로 사용하지 않습니다.

## 자동 업데이트 활성화를 위해 필요한 외부 단계
1. 운영자 소유 Chrome Web Store 개발자 계정 등록, 약관 동의 및 등록비 처리
2. 실제 동작 검증 및 게시 가능한 패키지/아이콘/실제 화면 캡처/개인정보처리방침 준비
3. 게시 항목 생성과 심사 제출
4. 심사 통과 후 베타 참여자에게 웹스토어 링크 제공, 최초 1회 설치
5. 이후 같은 웹스토어 항목으로 새 버전 제출, 승인된 버전은 크롬이 자동 업데이트
현재 웹스토어 계정 연결·등록·심사·자동 업데이트 활성화는 완료되지 않았습니다.
