전체 26개 항목 보기 · 선택 기능 포함

수동 체크는 네이버에서 직접 적용·확인한 뒤 표시해주세요. 필요한 기능만 골라 쓰세요.

네이버에서 감성 서식 마무리하기
  1. 인용구: 한 줄 감상을 선택한 뒤 네이버의 인용구 서식을 골라주세요.
  2. 구분선: 매장 정보와 이야기 사이, 마무리 앞에 넣으면 호흡이 생겨요.
  3. 소제목·강조: 소제목만 굵게, 본문에서 중요한 표현만 살짝 강조해주세요.
  4. 사진 설명: 사진 아래 짧은 캡션은 작고 옅은 글자로 정리해주세요.
  5. 장소: 글 아래 네이버 편집기의 장소 기능으로 방문한 매장을 추가해주세요.

복사는 인용문·구분선·캡션의 일반 서식을 포함해요. 네이버 전용 인용구 디자인·스티커·장소 카드는 네이버 편집기에서 직접 적용해야 해요. 붙여넣은 서식과 사진은 게시 전 확인해주세요.
